# CET4 背单词应用 - 启动说明

## 🚀 快速启动

### 方法1：直接运行命令（最简单）

1. 打开命令提示符（CMD）或 PowerShell
2. 进入项目目录
3. 运行以下命令：

```bash
python -m http.server 5173
```

4. 在浏览器中访问：http://localhost:5173

### 方法2：使用启动脚本

#### Windows用户：
- 双击运行 `run.bat`
- 或者在PowerShell中运行：`.\start.ps1`

#### Linux/Mac用户：
- 运行：`./start.sh`

## 🔧 如果启动失败

### 检查Python是否安装
```bash
python --version
```

如果显示版本号（如Python 3.14.7），说明已安装。

### 如果未安装Python
1. 访问 https://www.python.org/downloads/
2. 下载并安装Python
3. 安装时勾选"Add Python to PATH"
4. 重新启动命令提示符

### 检查端口是否被占用
```bash
netstat -ano | findstr :5173
```

如果端口被占用，可以使用其他端口：
```bash
python -m http.server 8080
```

然后访问：http://localhost:8080

## 📱 应用功能

### 学习模式
1. **📝 卡片翻转**: 点击翻转查看释义
2. **❓ 选择题**: 从4个选项中选择正确答案
3. **✏️ 拼写测试**: 根据释义拼写单词
4. **📖 例句填空**: 在例句中填写正确单词
5. **🔊 听音选词**: 听发音选择正确单词

### 学习管理
- **错词本**: 自动收集答错的单词
- **学习统计**: 查看学习进度
- **导入导出**: 支持多种格式

## 🆘 常见问题

### 1. 应用无法加载
- 检查浏览器控制台错误
- 确认所有文件路径正确
- 尝试刷新页面

### 2. 数据库错误
- 清除浏览器缓存和IndexedDB
- 重新启动应用

### 3. 性能卡顿
- 减少同时加载的单词数量
- 关闭其他浏览器标签

## 📝 注意事项

1. **首次使用**: 需要网络连接加载词汇表
2. **浏览器兼容**: 推荐使用Chrome/Firefox/Edge
3. **存储空间**: 确保浏览器有足够存储空间
4. **数据备份**: 定期导出学习数据
